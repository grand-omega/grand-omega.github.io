**Grand Omega** builds focused AI tools that run on hardware you already
own — local, self-hosted, single-user.

## Projects

- **[Project ZUN](/projects/project-zun/)** — a local image editing stack built on
  FLUX.1 Fill and FLUX 2 klein. Inference and LoRA training on a single
  consumer GPU, paired with a Rust API server and an Android client.
- **[Project Matrie](/projects/project-matrie/)** *(in development)* — AI bout
  analysis for competitive fencers and their coaches.
